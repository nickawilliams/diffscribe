# Agents

## Formatting

- Respect the configuration in `./.editorconfig`

## Commits

- Commit messages should be formatted according to the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification.
- Include a scope when appropriate.
- Prefer single-line commit messages.
- When changes can't be described by a single-line description, separate changes into multiple commits
- Refer to messages in the commit history for details not covered or unclear in these guidelines.
